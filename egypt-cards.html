TEACHER REFERENCE / KEEP SEPARATE FROM STUDENT CARDS

Egypt card key & model credits

The printed student cards hide artifact names. All sizes are approximate teaching spans, not verified museum measurements. Several models are replicas or reconstructions. Credits and interpretation notes are also available in the scanner’s details panel.

Mobile versions use resized and compressed textures, with mesh simplification where needed. Captured artifacts load the existing higher-detail textures when available. The two replica components were separated from a modern display. Source licenses apply; this collection is provided for noncommercial classroom study.

Camera & printing help

  • Use Safari on an iPhone or iPad. Allow camera access when asked. The published site uses HTTPS.
  • Keep all four corners of one square visible, in even light. Avoid glare, folds, and placing objects over the marker.
  • Start about 40–70 cm above a card and move until it is recognized. Models load on first detection.
  • Tap Capture while the object is visible. Drag to rotate and pinch or scroll to zoom. Tap Release to scan another card.
  • The four-card print layout uses 8.00 cm squares; the one-card layout uses 16.00 cm squares. Select the matching printed square size before starting the scanner.
  • If camera access was blocked, allow it in Safari’s website settings and reload. No camera recordings are uploaded.
