A skeleton.
Thirteen clues.
A room of investigators.

Place printed cards around your classroom skeleton. Students use Safari on an iPad to see an artifact hovering over its card in live AR, capture it for close inspection, and return it to the card.

Prototype for a classroom trial. The models are simplified reconstructions, not measured museum scans. Test a printed card on a school iPad before printing the full set. Live AR needs the marker visible. Capture deliberately keeps the object on screen after the marker leaves view; Return artifact restores live tracking over that same card.

Set and save the card views

In Teacher Mode, choose each artifact’s orientation, life-size reference dimension, and starting size. Connect GitHub in Teacher Mode for the teaching session using a fine-grained key restricted to otiz-ar with Contents: Read and write. Then Save to cards commits directly and reports when publication is complete. No GitHub confirmation page is needed for each save. Enter the key privately in Teacher Mode, not in the chat; it is kept only for that browser tab session. Students reload the usual scanner link to receive your saved choices. Existing cards and the launch QR keep working.

For four-to-a-page cards, start with an 8 cm marker width. Measure the outer black square and enter its exact width in Teacher Mode. At 100%, each object uses its reference life-size dimension. Museum measurements are used where available; other dimensions are labeled editable estimates. Live AR uses these physical measurements. If the initial object would be tiny or clipped, its local display size is fitted for visibility. Fit over card can do this again; Life size restores 100% of the reference dimension. Capture uses a separate screen zoom, with no 800% ceiling.

1. Prepare the cards and iPads

Open the published GitHub Pages link in Safari. The launch-sheet QR opens the scanner. Allow camera access, then try a printed card before using the full activity with a class.

  1. Print the launch sheet and one test card first. The browser print view contains all 13 numbered floor cards. Use the separate launch sheet for the QR code. Print the four-card layout in black and white on US Letter at Actual size / 100%, with one page per sheet in the printer dialog. Do not apply four-per-sheet a second time. If you use Fit or another paper size, measure a black square and update the marker width. All cards must use the same print scale.
  2. Keep the marker clear. Leave the full black square and surrounding white space intact. Use flat, matte paper or card. Glossy lamination and overhead glare can make tracking harder.
  3. Open the site in Safari on each iPad. Use the launch-sheet QR code and tap Start camera. Allow camera access. Safari needs the published HTTPS address, rather than a file opened from Downloads.
  4. Try card 06. Hold the rear camera roughly 40–70 cm above it. Include the whole square. Approach slowly; step back if you cannot see all four corners.
  5. Arrange the remaining cards. Leave about 30 cm between them and space for students to walk without stepping on cards. The positions below are a classroom arrangement, not a map of the actual discovery site.

3. Student task

  1. Scan a card. Before revealing the name, sketch the object and describe its shape.
  2. Suggest a material and a use. Point to a feature of the object to support your idea.
  3. Start in live AR, keeping the black square visible while you move around the hovering model. Tap Capture to keep it on screen for close inspection. Drag to rotate, pinch or use Bigger to zoom freely, and use Fit object to see the whole object again. Tap Return artifact to restore its previous AR size and orientation over the same card. If that card has moved out of view, point at it again. Capture is always reachable above the scene, even with details hidden. Use Hide details to tuck away the bottom panel and Show details to bring it back.
  4. Tap Reveal artifact name. Compare the reconstruction with the photograph in the collection.
  5. Choose three objects. What can they tell you about the person’s environment, skills, and needs?

Useful discussion prompt: “Which part is evidence, and which part is an interpretation?” Card 11 is especially useful: the grass weaving’s original purpose is debated.

Before the class: check one iPad

  • Camera blocked: use Safari’s website settings to allow the camera. A managed iPad may need school IT to permit camera access for the site.
  • Model does not appear: make the entire square visible, reduce glare, flatten the paper, move closer, and give it a moment. Try the printed test card rather than a small image on another screen.
  • Object disappears: in live AR, keep the whole marker visible. Use Fit over card if the model is too small or clipped. After Capture, the object stays on screen; use Fit object if zoomed too far in. Return artifact requires the same card to be visible again.
  • Page will not open at school: ask school IT to allow the GitHub Pages address on the student network. The published activity does not need student GitHub accounts.
  • Slow performance: scan one card at a time, close extra tabs, and reload Safari. The 3D collection can also be used without the camera.

About the reconstructions

The supplied 12-page PDF establishes the artifact numbers and photographic references. Some models use original simplified geometry to represent those objects in three dimensions. Card 1 uses the teacher-supplied GLB bark container with its original reference photograph. Card 2 uses the teacher-supplied GLB leggings with its original reference photograph. Card 3 uses the teacher-supplied GLB cap with its original reference photograph. Card 4 uses the teacher-supplied GLB arrow model to represent one arrow; its reference photograph remains the original class image. Card 5 uses the teacher-supplied GLB coat fragments with its original reference photograph. Card 7 similarly uses the teacher-supplied GLB dagger with its original reference photograph. Card 6 uses the teacher-supplied GLB axe with its original reference photograph. Card 8 uses the teacher-supplied GLB pressure flaker (retoucheur) with its original reference photograph. Card 9 uses the teacher-supplied GLB stone disc and tassel with its original reference photograph. Card 10 uses the teacher-supplied GLB footwear model while retaining the original photograph of inner shoe netting. Card 12 uses the teacher-supplied GLB backpack frame with its original reference photograph. Missing parts, surfaces and proportions are illustrative. Life-size scale uses the teacher’s reference dimensions and measured marker width; estimated reference dimensions are labeled in Teacher Mode. Card 13 adds the teacher-supplied GLB bow model; its collection image is a rendered preview, not a museum photograph. The original twelve card numbers stay the same.

Artifact names and short background notes were checked against the South Tyrol Museum of Archaeology’s equipment page and clothing page. Card 10’s reference photograph shows inner shoe netting; its 3D model is a fuller footwear reconstruction; card 11 is called a grass mat without presenting the cape interpretation as certain.

Camera frames are processed by AR.js in the browser. The activity code does not record, store or upload frames, collect student names, or keep student responses. Internet is needed for the initial site load. Hosting may apply its normal access and request logging.

Libraries: A-Frame 1.6.0, AR.js 3.4.7. Library notices are included with the site source.
